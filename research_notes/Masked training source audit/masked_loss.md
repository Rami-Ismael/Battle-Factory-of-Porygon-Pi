## How corruption and loss work

### Takeaway
Masked diffusion uses one noised copy of each sequence, with a per-example noise rate and weighted token reconstruction. It does not use the local complementary copies, clean teacher segment, or block-causal attention.

### Cited Findings
- `MDLMConfig` defaults to `time_epsilon=1e-3`, `loss_weight_type="scheduler"`, `loss_norm_type="token"`, `right_shift_logits=False`; absent a supplied scheduler, `MDLMTrainer` creates `LinearAlphaScheduler`. [Configuration and initialization](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/mdlm.py#L25-L51)
- Each example draws one independent `t = epsilon + (1-epsilon)*rand`, shared across its positions. Each eligible token then gets an independent Bernoulli mask with probability `1-alpha(t)`. Only positions with `labels != -100` are eligible. Selected positions become the tokenizer's mask token ID. This is not the local one-rate-per-32-token-block schedule. [Corruption](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/mdlm.py#L139-L166); [local block rates](https://github.com/Rami-Ismael/Battle-Factory-of-Porygon-Pi/blob/dc8f91c5f97879d285f64da00d82476b1537edce/code/src/textdiff_port.py#L148-L154)
- Linear alpha is `1-t`; scheduler weight is `-alpha'(t)/(1-alpha(t)+1e-6)`. Therefore default mask probability is `t`, and default reconstruction weight is `1/(t+1e-6)`, rather than plain mean CE over the sampled masked positions. `uniform` is an explicit alternative weight. [Scheduler formula](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/schedulers/alpha.py#L86-L107); [weight selection](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/mdlm.py#L85-L100)
- Exactly one explicit `model(...)` call occurs inside `compute_loss`, on the full noised `B x L` sequence, with optional attention mask. The trainer does not pass diffusion time to the model. It obtains full logits, computes CE targeting original `input_ids` at all positions, then multiplies by the sampled-mask indicator and weights. Unmasked eligible positions, prompt positions and ignored padding contribute zero to final loss, but full-position logits and CE are still computed. This call count is per microbatch loss evaluation, not per optimizer update or backward recomputation. [Forward and CE](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/mdlm.py#L168-L192)
- Default normalization divides the weighted sum by **all eligible tokens**, not the random number of selected masks. Sequence normalization first divides each sequence by its eligible count then averages the batch. Batch normalization divides only by batch size. All denominators are clamped where applicable. Thus an example with no selected masks contributes zero, without a zero-mask division. [Normalization](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/mdlm.py#L200-L212)
- Standard supervised fine-tuning mapping applies the chat template to the full conversation and, by default, labels the prefix preceding the final assistant message `-100`. The prefix includes whatever generation prompt the tokenizer produces. Combined with the eligibility rule, these prompt tokens are held clean and unscored, but remain in the forwarded input. Setting `mask_prompt_loss=False` makes them eligible for corruption and scoring. [SFT mapping](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/utils/data.py#L225-L253); [eligibility](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/mdlm.py#L139-L170)
- The MDLM trainer requires right padding. The LLaDA and autoregressive-to-diffusion SFT examples deliberately use `label_pad_token_id=tokenizer.pad_token_id` and remove the attention mask, with comments saying padded end-of-sequence tokens are trained and visible. Therefore their padded tails are eligible noise and targets, whereas labels `-100` would exclude them. This is a recipe choice, not a universal MDLM requirement. [LLaDA SFT collator](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/examples/llada/sft.py#L104-L119); [A2D SFT collator](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/examples/a2d/mdlm/sft.py#L104-L119); [wrapper removes mask](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/utils/collators.py#L58-L69)
- `prediction_step` calls the same `compute_loss`, which draws fresh noise. There is no evaluation-specific seed or mask bank in that function. A stable validation comparison therefore needs an explicit implementation decision to reuse corruption, rather than treating one evaluation as exact likelihood. [Prediction path](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/mdlm.py#L102-L116); [random draws](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/mdlm.py#L149-L162)

### Inferences
- Under the ideal continuous uniform draw, expected eligible masking fraction at default epsilon is `(epsilon+1)/2 = 0.5005`. This is arithmetic from the code, not measured hardware utilization. The model still forwards the full sequence, so half the supervised targets does not imply half the forward cost.
- A direct local masked-loss implementation should use `sum(CE * masked_mask * weights) / count(labels != -100)` for the default MDLM recipe, with per-example noise. Reusing the current selected-token mean changes the objective.
- Stock padded-EOS training may matter to generation length; no Pokémon result establishes which padding policy wins. The chosen policy must be explicit and consistent in validation.

### Gaps
- No runtime verification of stochastic or numerical behavior was permitted. No claim here establishes training speed, convergence, team quality or a winning candidate.

## Which trainer family and attention alignment apply

### Takeaway
There is no single shift or weighting rule for every masked checkpoint. LLaDA, converted bidirectional models and the BERT example use generic MDLM defaults, while Dream adds shifted logits and geometric context weights.

### Cited Findings
- LLaDA, autoregressive-to-diffusion full-sequence training, and ModernBERT supervised examples construct `MDLMTrainer` and derive arguments from `MDLMConfig`. [LLaDA](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/examples/llada/sft.py#L57-L64); [LLaDA trainer](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/examples/llada/sft.py#L104-L119); [converted model](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/examples/a2d/mdlm/sft.py#L57-L64); [BERT](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/examples/bert/sft.py#L57-L64)
- When `right_shift_logits=False`, logits at position i are compared against token i. With `True`, logits become `[logits_0, logits_0, logits_1, ...]`, preserving length. The preprocessing prepends a beginning-of-sequence token with ignored label unless every sequence already begins with label `-100`. This is checkpoint-specific alignment, not a property one can infer from the name diffusion. [Pre/postprocessing](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/mdlm.py#L60-L83)
- Dream's config requires `right_shift_logits=True` and defaults to `cart[geo_p:0.3]`. Its weight sums geometric-distance contributions from unmasked positions to each masked position, excludes distance zero, and does not use t directly. The distance weight is `0.5*p*(1-p)^max(abs(distance)-1,0)`. It is not generic inverse-mask-rate weighting. The implementation constructs an `L x L` distance matrix and performs a `B x L` by `L x L` multiply. [Dream weights and config](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/pipelines/dream/trainer.py#L9-L77)
- Dream's SFT example uses its own collator with per-batch response cutoff enabled by default, choosing one response length from the batch and trimming longer responses before collation. It pads labels with the tokenizer pad ID but retains the collator attention mask. Thus copying LLaDA's collator into Dream would discard a real recipe difference. [Example defaults](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/examples/dream/sft.py#L49-L74); [trainer/collator](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/examples/dream/sft.py#L138-L151); [cutoff implementation](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/pipelines/dream/utils.py#L44-L70)
- The converted Qwen3 model explicitly replaces its causal mask with a bidirectional padding-only mask. LLaDA attention hardcodes `is_causal=False` in its attention call, and Dream does too. A stock causal model plus a masked loss alone is therefore not the same source implementation. [Converted Qwen3](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/pipelines/a2d/models/qwen3/modeling_qwen3.py#L84-L108); [LLaDA attention](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/pipelines/llada/models/modeling_llada.py#L631-L659); [Dream attention](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/pipelines/dream/models/modeling_dream.py#L419-L430)
- Block diffusion remains a separate `BD3LMTrainer` with block diagonal noisy attention and earlier clean blocks. Its existence does not make those block operations appropriate for masked full-sequence training. [Block mask](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/trainers/bd3lm.py#L42-L90)

### Inferences
- Remove the global local `SHIFT=True` assumption. Store an alignment choice with each selected checkpoint and use the same choice in train, validation and sampling.
- Dream's CART implementation introduces sequence-quadratic weighting work beyond model attention. The source proves tensor shapes and operations; its wall-clock contribution is unmeasured.

### Gaps
- Candidate-specific configuration and weights must be pinned separately before asserting compatibility. This audit pins library source only, not Hugging Face model revisions or external dependency implementations.

## What sampling and block optimizations change

### Takeaway
The generic masked sampler repeatedly forwards the complete prompt-plus-generation canvas. Its optional generation windows do not impose the block model's attention rule or make the local clean-context cache valid.

### Cited Findings
- MDLM sampling initializes clean prompts and mask tails, then chooses generation windows and a per-window step budget. Every refinement call forwards the full canvas, not only the active window. Only currently masked positions are updated; original prompts stay fixed in the conditional row. [Canvas and window schedule](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/samplers/mdlm.py#L97-L155); [full forward and update](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/samplers/mdlm.py#L160-L230)
- With classifier-free guidance enabled, one explicit model call contains both conditional and unconditional rows, doubling its batch. The unconditional row masks original prompt tokens except configured keep-token IDs. It combines `un_logits + (cfg_scale+1)*(cond_logits-un_logits)`, so its scale is offset by one relative to local `guidance*cond+(1-guidance)*uncond`. [CFG](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/samplers/mdlm.py#L119-L127); [CFG call](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/samplers/mdlm.py#L164-L177); [local combine](https://github.com/Rami-Ismael/Battle-Factory-of-Porygon-Pi/blob/dc8f91c5f97879d285f64da00d82476b1537edce/code/src/textdiff_port.py#L265-L280)
- Forward calls equal the sum of each window's `effective_steps` in this sampler; transfer scheduling removes all-zero transfer steps and pads to the largest remaining count across batch rows. Therefore nominal `steps` alone does not give exact forward count for every length/batch configuration. No key/value-cache argument is passed by the generic MDLM loop. [Loop and calls](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/samplers/mdlm.py#L157-L177); [step compaction](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/samplers/utils.py#L28-L69)
- Dream's sampler also forwards full canvas, optionally with doubled CFG batch, then shifts logits and samples masked positions. Its whole-canvas loop is distinct from the generic generation-window loop. [Dream loop](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/pipelines/dream/sampler.py#L149-L188)
- The local block loss concatenates noisy/complementary/clean segments and only projects selected target hidden states through the vocabulary head. Its `trim`, `split`, `detach` and reduced-noisy-layer machinery explicitly depend on the separation of clean and noisy block contexts. [Local loss](https://github.com/Rami-Ismael/Battle-Factory-of-Porygon-Pi/blob/dc8f91c5f97879d285f64da00d82476b1537edce/code/src/textdiff_port.py#L157-L207); [local layouts](https://github.com/Rami-Ismael/Battle-Factory-of-Porygon-Pi/blob/dc8f91c5f97879d285f64da00d82476b1537edce/code/src/textdiff_port.py#L438-L488)

### Inferences
- Drop block masks, complementary/clean concatenation, last-clean-block deletion, prefix trimming justified by block non-attention, detached clean passes, shared-clean caching and reduced-layer noisy decoder as equivalent masked-training optimizations. In a bidirectional model, prompt hidden states depend on noisy answer tokens. A fresh equivalence proof would be required for any replacement.
- A selected-position vocabulary projection is worth investigating for the masked loss because unselected CE is later zeroed, but the current local hidden-state slicing and shift cannot be copied unchanged. Preserve weights and the all-eligible denominator. This is a proposed optimization, unverified for runtime or gradients.
- One copy versus local 3L or 4L token layouts is a code-level input-token count comparison, not a dollar or throughput ratio. Attention density, parameter count, vocabulary projection, precision and optimizer/checkpointing choices still differ.

### Gaps
- No laptop generation timing, cache optimization correctness, GPU memory measurement, dollars/example estimate, quality result, or block-to-masked speed transfer has been verified. No new blog was used or found in this source-only scope.

Its `return_logits=True` branch always shifts regardless of `SHIFT`, and `verify_layouts.released` also hardcodes shifted indexing. Those verification helpers cannot establish same-position masked-model equivalence as written. [Local normal and returned-logit branches](https://github.com/Rami-Ismael/Battle-Factory-of-Porygon-Pi/blob/dc8f91c5f97879d285f64da00d82476b1537edce/code/src/textdiff_port.py#L198-L207); [hardcoded verification branch](https://github.com/Rami-Ismael/Battle-Factory-of-Porygon-Pi/blob/dc8f91c5f97879d285f64da00d82476b1537edce/code/src/textdiff_port.py#L508-L513).
