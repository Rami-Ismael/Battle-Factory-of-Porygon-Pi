Setting

Competitive Pokémon Singles, Showdown, Gen 1–4 OU (+UU/NU/Ubers; 16 rulesets). No team preview → maximal partial observability, longest battles. Evaluation focus: OU.

Dataset (Sec. 3, App. D)

sourcepublic spectator replays, 2014 → Sept 2024 cutoff
reconstructionsimulate PS protocol → estimate both initial teams from revealed info → infer never-revealed parts from usage data + similar replays → backfill POV knowledge → emit agent format; ambiguous cases discarded
size475k battles → 950k POV trajectories → 38M timesteps ("RPS 950k"); pipeline now 3.5M traj incl. Gen 9 OU
missing actionsunrevealed choices (e.g. full paralysis) filled by a small BC model; better filler helped IL, not RL (App. D.1)

POMDP (Sec. 4, App. E)

obs87 text tokens + 48 numeric features; only the opponent's active Pokémon — memory must carry the rest
actions9 discrete: 4 moves + 5 switches, turn-dependent meaning, fixed order in text
rewardR = rhp + ½ rstat + rfaint + 100·rwin
framingopponent policy πo and team co are latent variables of T; Bayesian-RL / meta-RL; black-box sequence model infers them in-context

Finding: any RL row ≫ IL; RL rows ≈ each other. Critic: 4-ensemble, TD, multi-γ heads (act on γ = 0.999). SynRL-V2 uses two-hot classification critic → more pessimistic Binary filter.

Critic loss (from AMAGO / AMAGO-2, not printed in Metamon)

yt = rt + γ Q̄(ht+1, a'∼π̄(ht+1));   LCritic = (Q(ht,at) − yt)²;   joint = Σ Lactor + 10·LCritic

Target heads τ = 0.004 (no target sequence model); critic blocked from actor gradient; 4-critic ensemble, mean → V(h); multi-γ heads, act on .999; PopArt on y. SynRL-V2: two-hot CE, L = −twohotB(y)T log QB(h,a), 96 bins on [−110,110]. 🟢 AMAGO App. A · 🟢 AMAGO-2 Sec. 3.

Transfer to this project — verdict

HIGH for the battle-policy strand: BC floor → filtered-BC step → self-play with an OOD watermark; cross-play can hide self-modelling, keep an external column. LOW–MED for f / team search: no team building; singles, no preview; one line — team design "converges to an equilibrium that helps narrow the search to perhaps many thousands of meaningfully distinct teams".
