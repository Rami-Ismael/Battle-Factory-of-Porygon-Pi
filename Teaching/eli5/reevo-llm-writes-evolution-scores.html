ELI5 · NeurIPS 2024

ReEvo

The LLM writes little pieces of code. A contest scores them. The best code survives and gets rewritten better. That's the whole paper.

1 · Hard puzzles run on a "rule of thumb"

For puzzles too big to solve perfectly — like routing a delivery truck — the solver leans on one tiny function that says "try this next." That function is called a heuristic. Humans used to write it by hand, and writing a good one is hard.

2 · The LLM is a chef who writes recipes

ReEvo asks the LLM to write many versions of that function — like a chef scribbling a stack of recipe cards. The LLM never solves the puzzle itself. It only writes the rule.

3 · A taste test gives every recipe a number

Each piece of code is actually run on real puzzle instances. Shorter truck route → better score. No opinions, no vibes — the score comes from execution.

4 · Evolution, but the LLM does the breeding

Keep the winners, drop the losers — classic evolution. But crossover and mutation are done by the LLM: it reads two good recipes and writes a child that combines their ideas, then tweaks it.

5 · The special trick: it writes itself notes

This is the "Re" in ReEvo. Before breeding, the LLM compares the better parent to the worse one and writes a short note: "the winner won because…" The notes pile up into a notebook that steers every later rewrite. The authors call it a gradient made of words — direction to improve in, without any math derivative.

6 · The whole loop

Write → score → pick parents → reflect → breed → tweak → score again. Around and around, until the code is better than what a human expert wrote by hand.

Why this is in the vault

Not for building teams. The reuse here is letting the LLM evolve pruning rules — filter code judged with no battles at all: how much of the search space it cuts × how many collected meta teams it keeps. The paper note's verdict: "MED for the owner's pruning-rule application … LOW for the paper's own construction-heuristic loop."

Paper: ReEvo — Large Language Models as Hyper-Heuristics with Reflective Evolution, NeurIPS 2024. 🟢 open access.
