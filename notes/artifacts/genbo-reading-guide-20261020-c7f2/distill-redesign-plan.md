# An explorable GenBO article

The question is how the same observations teach a proposal differently under binary elite selection and observed-improvement weighting. This is a reading companion, not an implementation of GenBO or a Pokémon experiment.

## Design alternatives

Article with linked figures, chosen:

    restrained publication header
          question / short abstract
          paper reference
    [ CEM weights ] [ improvement weights ]
             one score control
          argument              margin note
    [ shared loop, linked explanation       ]
          objective            equation note
    [ threshold / explicit empty state     ]
          transfer             source note
          own notes and reading tasks

Scroll-driven presentation, rejected:

    sticky full-screen diagram | changing prose

It would make comparison depend on scrolling and conceal the whole argument. This subject benefits from stable side-by-side evidence and user controls.

## Tokens

- Paper #ffffff.
- Ink #2c3543.
- Secondary #657184.
- Figure ground #f4f7fb.
- CEM amber #b97520.
- Utility blue #416fc3.

Use Avenir Next or Helvetica Neue for titles, figure annotations, and controls. Use Charter or Georgia for prose. Use serif mathematical notation, not monospace decoration. Body text is about 19px with generous leading and a measure under 70 characters. Headlines remain one color.

Prose is left aligned on a narrow central column. Figures extend into both margins. Sidenotes sit alongside the exact claims they qualify, then join the flow on small screens. No rounded-card chapters, accent-word headline, uppercase labels, scroll entrances, or decorative background movement.

## Review of the direction before building

The existing hero, pills, rail, panels, and progress display made a research explanation feel like an app checklist. Replace these with an argument and its evidence. The distinctive element is the linked eight-team figure, not ornamental typography or a large metric. A second figure moves the improvement threshold and retains the all-zero case. The diagram is an explanatory map, not animated decoration.

References: https://distill.pub/2017/momentum/ and https://distill.pub/2019/visual-exploration-gaussian-processes/.

## Motion contract

Occasional pointer-triggered state indication and explanation only. Bar transforms retarget from their current presentation over 220ms using the existing ease-out token. Range manipulation updates immediately. No entrance sequences, autoplay, decorative loops, or motion on keyboard input. Reduced motion retains readable feedback without movement. The independent motion review must inspect the completed source before publication.

## Preservation and ownership

Root owns the site's HTML and publication. Other agents review read-only. Keep the same project ID and audience. Keep the existing localStorage key and notes/complete fields, export, paper links, no-weight fallback, and source caveats. Original local HTML remains available as an earlier artifact. Update the hosted source only after opening its current source repository.
