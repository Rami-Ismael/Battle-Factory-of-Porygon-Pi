# Introduction to Evolutionary Computing: reading guide

Selected on 21 October 2026 for the Pokémon counter-team search project.

**Use this as the detailed follow-up to [[Essentials of Metaheuristics - reading guide]]. Start with chapter 3 only.**

The book is by A. E. Eiben and J. E. Smith. These chapter numbers refer to the **second edition, 2015**, verified from the [official publisher contents](https://link.springer.com/book/10.1007/978-3-662-44874-8). Full access requires purchase or institutional library access. No free author copy was verified.

## Your first reading path

| Order | Read | Connect it to your project |
| --- | --- | --- |
| 1 | [Chapter 3: What Is an Evolutionary Algorithm?](https://link.springer.com/chapter/10.1007/978-3-662-44874-8_3), pages 25–48 | Follow the common search cycle using complete Pokémon teams as candidates. |
| 2 | [Chapter 4: Representation, Mutation, and Recombination](https://link.springer.com/chapter/10.1007/978-3-662-44874-8_4), pages 49–78 | Understand how the representation determines which team changes an operator can make. |
| 3 | [Chapter 5: Fitness, Selection, and Population Management](https://link.springer.com/chapter/10.1007/978-3-662-44874-8_5), pages 79–98 | Separate scoring a candidate from choosing which candidates guide the next round. |

Use the chapter that answers the question you currently have. This path does not require reading both textbooks cover to cover or changing the current experiment queue.
