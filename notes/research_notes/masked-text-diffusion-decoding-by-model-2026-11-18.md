A **sampler** is the loop that selects masked positions and fills their token ids. The **text decoder** later converts those ids into text and a team. Confidence order ranks a proposed token's probability; margin order ranks the gap between the two largest probabilities; entropy order ranks how concentrated the whole token distribution is. A linear schedule reduces the remaining mask fraction uniformly in time. A block sampler finishes one span before moving to the next. A right shift uses the prediction at position i−1 to fill position i. A beginning-of-sequence token is abbreviated BOS. Classifier-free guidance compares conditional and unconditional predictions; `cfg` is its strength. Key/value caching reuses attention states from earlier model calls. These terms distinguish the mechanisms implemented below, rather than treating every parameter named `remasking` as permission to revise an already filled token. [dLLM loop](https://github.com/ZHZisZZ/dllm/blob/ca176752fbceec49c6b4777a2c18ae88e4eb10ed/dllm/core/samplers/mdlm.py#L183-L230), [Dream loop](https://huggingface.co/Dream-org/Dream-v0-Base-7B/blob/6572adb5535263e4d1a337b56942ba48b6dee2a9/generation_utils.py#L387-L450)

Below, L means generated length, T means sampler steps, and B means block length. Top-p retains the smallest vocabulary set reaching cumulative probability p; vocabulary top-k retains k tokens. Choosing k *positions* or k proposals is a different operation. A function evaluation is one model call, sometimes abbreviated NFE for number of function evaluations. Gumbel-max draws a token by adding Gumbel-distributed noise to its logits and taking the largest value; at temperature 0 it takes the largest unperturbed logit. Perplexity measures predictive uncertainty and lower is better. Task scores are percentages unless the row says otherwise. Benchmark abbreviations are retained for traceability: Big-Bench Hard is BBH, Massive Multitask Language Understanding is MMLU, its harder variant is MMLU-Pro, Mostly Basic Python Problems is MBPP, and the AI2 Reasoning Challenge challenge split is ARC-C. GSM8K tests grade-school mathematics, MATH tests competition mathematics, HumanEval tests code, and ROCStories evaluates story completion. Graduate-Level Google-Proof Q&A is GPQA; Social Interaction Question Answering is SIQA. ROUGE1/2/L compares generated and reference text using unigram overlap, bigram overlap and longest common subsequence. Pass@1 is the success rate of one generated answer, and tok/s means generated tokens per second. [dLLM Table 3](https://arxiv.org/html/2602.22661v1#S4.T3), [DiffuLLaMA Table 1](https://arxiv.org/html/2410.17891v3)

This extends the November 16 note and closes its missing-code, model-card and table-extraction items. The verified repository revisions are snapshots inspected for this note, not proof that those revisions generated historical paper tables. Each later-work row distinguishes a new sampler, a training or guidance change, a fresh baseline run, and a borrowed score. Unless a row establishes the original configuration, a later paper's measured improvement is against its own within-paper baseline, not a verified rerun of every setting used by the original authors. Selection favors exact-checkpoint use and direct relevance; citation counts were not verified.

## Project evidence already established

Issues [#165](https://github.com/Rami-Ismael/Battle-Factory-of-Porygon-Pi/issues/165) and [#236](https://github.com/Rami-Ismael/Battle-Factory-of-Porygon-Pi/issues/236), including their comments, establish the local starting point. Only dLLM's MDLM sampler and its uncached Fast-dLLM LLaDA sampler worked correctly on these masked Qwen models. The project's confidence-order sampler matched dLLM token for token when configured alike. Copying visible values requires the trained alignment: right shift for DiffuGPT, DiffuLLaMA and Dream, no shift for masked Qwen, and `<s>` first for DiffuLLaMA. Those are project tests, not published sampler gains. The project's linear transfer arithmetic, Gumbel-max token draw and confidence selection are pinned at [memory benchmark lines 75–130](https://github.com/Rami-Ismael/Battle-Factory-of-Porygon-Pi/blob/ad7fb0cd30d7a88fbbb86f8036a40c51de7ed6b8/code/scripts/masked_diffusion_memory_bench.py#L75-L130). Paper Algorithm 2 and §3.4 describe random ancestral unmasking with linear noise `alpha(t)=1-t`, categorical token draws and preservation of revealed tokens, via Eq. 4. Algorithm 1 describes training, not sampling; the old note's reference to Algorithm 1 as sampler needs correction. §3.3 retains the autoregressive next-position shift. [Paper v3](https://arxiv.org/html/2410.17891v3#S3).

External `generate_samples` ranks sampled-token log probabilities, keeps `floor(initial_masks*t/T)` lowest scores masked, and only fills positions still masked. It does not revise earlier commitments. This is a linear remaining-mask count, not random Bernoulli transfer. Sampling divides logits by `logits_temp`, then categorical draws; `gsm=True` instead takes argmax. Top-p calls are commented out, and no vocabulary top-k is applied. Shift is implemented by prepending original position 0, shifting sampled ids/scores right one, and removing first position on output. No block/semi-autoregressive loop. ## Dream 7B Base

### Authors' sampler

Pin Dream model code to Hugging Face revision `6572adb5535263e4d1a337b56942ba48b6dee2a9`. `DreamGenerationConfig` defaults are temperature 0, top-p None, top-k None, epsilon .001, steps 512, alg `origin`, alg_temp None. [generation_utils.py L99-L110](https://huggingface.co/Dream-org/Dream-v0-Base-7B/blob/6572adb5535263e4d1a337b56942ba48b6dee2a9/generation_utils.py#L99-L110).

Raw default `origin` fills masks independently with probability `1-s/t`, filling all on last step. Uniform timestep grid `linspace(1,.001,steps+1)`. Whole response, no block parameter. The loop only writes to currently masked positions, so filled tokens stay filled. Right shift is `cat([logits[:,:1],logits[:,:-1]],dim=1)`. [L387-L450](https://huggingface.co/Dream-org/Dream-v0-Base-7B/blob/6572adb5535263e4d1a337b56942ba48b6dee2a9/generation_utils.py#L387-L450). The shift also appears in paper §4.1/Figure 2. Other options are top-probability order `maskgit_plus`, top-two probability margin `topk_margin`, and negative-entropy order `entropy`. ## Open items

- The historical command-to-result mapping remains incomplete for DiffuGPT/DiffuLLaMA and Tiny-A2D. Current library, model-card, standalone, workflow and evaluation defaults are recorded separately above. They do not establish which route produced every original table cell.
- DiffuGPT Figure 5's precise plotted heights were not extracted. Its temperature/top-p arms and step counts were verified; Table 6 is qualitative, and Table 8 belongs to another checkpoint. GPT configuration-derived output lengths beyond the verified YAML remain unextracted.
- LSD+'s target-specific temperature, vocabulary filtering, length, alignment, start-token wrapper and revision behavior remain unverified; the inspected public code did not expose the target adapters. P2's DiffuLLaMA target configuration is similarly incomplete. Their measured results do not justify inventing missing settings.
- Dream's MBPP official script says three shots while its paper labels four. LLaDA's paper does not give temperature and vocabulary-filter settings for every reported table. Current script revisions are not historical run provenance.
- Feedback's paper says block16/temperature0 while its pinned code uses block8 and temperature .1 in generation and revision. VGB's table budget16 differs from current config default8. TrajDLM's full-sequence ablation step count, shift and vocabulary filters remain unverified. The Coder card's historical score-generation recipe is not established.
- Later cache/sampler papers do not all disclose complete start-token, shift, temperature and vocabulary-filter settings. Missing fields mean unverified, not disabled. SlowFast's exact confidence thresholds were not extracted, and its Dream variant is not counted here without exact checkpoint verification.
- Search scope covered exact checkpoint strings, shortened masked Qwen names, Tiny-A2D plus sampler terms, DiffuGPT-S/M and DiffuLLaMA plus sampling/baseline/temperature/remasking/initialization, and Fast-dLLM/dKV-Cache/ReMDM cross-checks.
