Seven versions of the discrete diffusion model

Each version was fine-tuned with one change to its training labels or training mix, then asked for a win rate. Win rate = wins ÷ 49 battles, one against each distinct top-50 meta team, with the behaviour-cloning bot on both sides. Effective species = exp(entropy) of species counts across a group's 64 teams; higher means the teams use more Pokémon.

Every add-on to the cross-entropy method loop: how it works and what it did

Each card is one change to the plain search loop (the cross-entropy method: write teams, battle them, fine-tune on the elites for 40 epochs, repeat), run for 3 generations on 3 seeds. Each diagram shows how the add-on works, on example teams made up for illustration; the numbers under it are the measured results. A elite line-up is a set of six species battled at or above the elite cut 0.531 (items and moves ignored). An add-on works only if it ends above the plain loop in all 3 seeds and its finalist interval stays above −0.03.
