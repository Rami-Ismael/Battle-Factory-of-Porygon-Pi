Do precise labels make a better team generator?

A team's label is its win rate against the meta. With 49 battles that number is noisy; with 192 or more it is precise. This ablation trains the same diffusion model three times, changing only which labels it learns from.

Win rate = wins ÷ battles against the top-50 meta teams, with the behaviour-cloned battle policy playing both sides. Generated teams get one battle per meta team (49 battles). Real meta teams average 0.531 against each other.

The same team, labelled twice

2,144 teams in the matchup matrix have 192 or more battles against the meta. For each one, a second label can be drawn from its own recorded battles: one battle per meta opponent, picked at random, 49 in all. That is the precision every search-loop label has.

Three training sets

All three fine-tunes start from the same original model and use the same recipe: 600 steps, batch 64, half of each batch the model's original training teams with the label hidden, half labelled teams. Only the labelled half changes.

What this does not show

  • One training seed per arm. The intervals cover team-to-team noise in the evaluation, not seed-to-seed variation in training.
  • The precise teams are not a random sample: about half were re-battled on purpose to cover the whole win-rate range. The noisy arm uses the same teams, so that comparison is clean; the comparison with every team is not.
  • This tests the model alone. Inside the search loop the ridge and the retraining also shape what gets built.
