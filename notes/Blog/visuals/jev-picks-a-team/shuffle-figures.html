Shuffling Jev's Move List

Jev picks a move from a list. Does the order of that list change which move it picks? Seven figures from the run of 2026-10-27, every number taken from it.

One question, two orders

Every question in the experiment looks like this one: a held-out team with one move hidden, and every legal move offered as an option. The same options go to Jev twice, in alphabetical order and in a shuffled order.

How the experiment separates order from noise

Jev does not always give the same answer twice. So a changed pick under shuffling means something only next to how often the pick changes with no shuffle at all.

Checking the measurement before spending

Two fake choosers run on the same 300 real questions per grid, with no calls to Jev. One always takes the first option; the other always takes the same move by name. They mark the two ends of the scale, so Jev's number can be read against them.

How often the order changes the pick

Half the changes are the same four moves in a new order

A changed pick is not always a new move. Often Jev, shown the shuffled list, picks a move it already chose for another slot of the same Pokémon. The moveset is the same; only the slot changed.

No pull toward the top of the list

A model that reads only the top of a list would pick early positions more often. Jev's picks spread almost evenly through the shuffled list.
