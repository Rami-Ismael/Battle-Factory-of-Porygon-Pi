The larger study has 50 random originals and 50 frozen placement entries. These first four placement entries cannot establish what happens across the full cohort. The extra edits let you explore every displayed Pokémon; they do not change this original two-edit sampling comparison.

What the statistic removes—and what it keeps

For each edit, the recorded estimator is mean(d)² − sample variance(d) / 3, where d is edited minus original win rate in each independent battle panel. We average the two edits within each original team, then give each original equal weight.

The correction removes the expected sampling-noise contribution under independent panels. A corrected estimate can be negative; it is retained rather than clipped or square-rooted. The observed absolute-change statistic still contains battle noise.

The random originals average only 2% win rate in this pilot. That floor constrains how far a replacement can reduce their win rate. The difference between groups therefore needs to be interpreted alongside their baseline performance.

The 95% intervals resample original-team identity clusters. They are exploratory with only four clusters per group. The random teams came from the frozen HPS corpus, not a uniform sample of all legal teams. The full placement snapshot includes ranked-season and ladder entries as well as tournaments.

A common scale does not make the edits equivalent.

One move, one categorical stage and a coordinate step define different neighborhoods. These results describe the sampled regions and edit rules; they are not a universal ranking of smoothness.

Objective bounds, reference regions and uncertainty

The recorded analysis uses fixed objective bounds of 1 for win probability, 50 for Pest Control and 8.4 for Hartmann-6. Values here are already normalized in the source data; no sample-dependent rescaling is applied.

Both benchmarks have four reference points and two neighbors per point for each displayed step. Pest Control uses independent replicate evaluations with 100 simulated trajectories per evaluation. Hartmann-6 is deterministic, so its interval describes variation across reference points rather than evaluation noise. The benchmark points are random reference regions, not analogues of top placements.

Hartmann-6 points are sampled inside [0.05, 0.95]⁶. Each edit changes one coordinate by the selected signed step, without boundary clipping. Pest Control has 25 categorical stages with five choices per stage.
