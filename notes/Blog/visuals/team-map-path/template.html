How the map is made

    

    
Each loop generation proposes 512 teams and battles 128 of them. Those 128 are the faint dots for the current generation. The path joins the team with the highest label in each generation. Labels are 50 battles each, one against every top-50 meta team, with the behaviour-cloned policy on both sides, so a best-of-128 label runs high. When the best 16 of each run were re-battled 196 times each, they scored 0.655 to 0.735.

    
Data: the 2026-10-08 diversity-methods run, control and taboo arms, three seeds, six generations, all starting from the same generation 0. The map is fitted on archetype labels, so the pools separate by archetype by construction. Two dots close together can still be different teams; hover a dot to see its six.
