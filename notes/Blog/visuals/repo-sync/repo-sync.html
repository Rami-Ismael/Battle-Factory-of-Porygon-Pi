Where the files live

Battle Factory of Porygon-Pi · 2026-10-08

The project exists in two places. The copy I edit lives on my laptop: an Obsidian vault of notes and a folder of code. The copy on GitHub is a mirror of it, laid out as two folders, notes/ and code/, so a visitor finds the writing and the program in one repository.

The question the figure answers is what happens when a file changes in either place. Step through it, or edit and sync as you like.

The mirror is one-way on purpose. The laptop is the only place a file is written, so there is never a merge to resolve and never a question of which version is the real one. A typo spotted on github.com gets fixed in Obsidian, and the next sync carries it over.

The sync copies only what each folder's own ignore rules allow. That keeps the Obsidian settings, the Python environment and about 1.6 GB of battle results at home, which is why a fresh clone has the code but not the datasets.

Sync script: tools/sync.py in the repository. tools/sync.py --dry-run lists what would change without touching anything.
