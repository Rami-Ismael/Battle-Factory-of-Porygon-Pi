Choose what adds value

Submodular maximization · one greedy decision at a time

Lesson 0010 · 2026-09-07 · 5 minutes · Reference · Earlier coverage lesson

Your win: calculate a candidate’s added coverage and choose the next candidate. This serves your counter-team project’s coverage formulation of f.

1. What does this candidate add?

Here is an invented coverage model. Each candidate covers a fixed set of opposing meta teams. Coverage is a modeling assumption here, not a claim that one Pokémon defeats an entire team.

CandidateMeta teams covered
A1, 2, 3, 4
B1, 2, 3
C4, 5, 6

Let f(S) count distinct covered meta teams. Starting empty, A adds four. After choosing A, B adds zero and C adds two. Count newly covered opponents; count each opponent once.

Δ(x | S) = f(S ∪ {x}) − f(S)

This is the marginal gain: value after adding x minus value before. 🟢 Definition 1.1.

You already selected C. What does adding A contribute?

C covers {4,5,6}. A adds {1,2,3}. The total rises from 3 to 6, so the gain is 3.

2. The rule behind the overlap

Submodular means Δ(x | P) ≥ Δ(x | Q) whenever P ⊆ Q and x ∉ Q. The same candidate cannot add more to a larger existing set. Equality is allowed. 🟢 Definition 1.2.

Compare adding B to the empty set (+3) with adding B after A (+0). A has already covered everything B offers. This example illustrates the rule; proving submodularity requires it for every eligible comparison.

For nested sets P ⊆ Q, which gains violate diminishing returns?

The last case increases the same candidate’s marginal gain from 1 to 5. A hypothetical combo bonus could create this pattern.

3. Maximize with a selection limit

maximize f(S), subject to S ⊆ V and |S| ≤ k

Greedy: start empty; repeatedly add the candidate with greatest current marginal gain, recalculating each round. 🟢 §2.

With two slots in our example, A is the first pick. The second slot goes to C: two new opponents versus B’s zero. Selecting the two largest standalone scores would leave a tie between B and C and could waste the slot.

When the guarantee applies.

If f(∅)=0, f is monotone (adding candidates never lowers value), and f is submodular, exact greedy under a size limit achieves at least 1−1/e ≈ 63.2% of optimal value. 🟢 Theorem 1.5.

In this toy instance greedy achieves 6 out of the best possible 6. The 63.2% figure is a lower bound on objective value, not a predicted battle win rate. A learned team-level matchup predictor needs its own justification; it does not inherit these properties from the coverage example.

A combo makes x add 0 alone but 8 after its partner. What follows?

Take P empty and Q containing the partner. Then 0 ≥ 8 is false. This one counterexample rules out submodularity for that objective.
