The surrogate-assisted search loop

Reference sheet · compressed from Lesson 0004 · source: 🟢 Zhang et al., GECCO 2022

The loop

data D ← a few real-evaluated candidates
repeat until real budget (N evaluations) exhausted:
  1. TRAIN    surrogate ŝ on D            # ŝ : encoding → (objective, measure₁, measure₂)
  2. SEARCH   run the optimiser on ŝ only  # ~10⁶ iterations, zero simulated games
              → surrogate archive of predicted-good, predicted-diverse candidates
  3. GROUND   evaluate chosen candidates on the simulator   # the ONLY expensive arrow
              → insert into the real archive, append labels to D
return the real archive

Price of each arrow

arrowcost in DSA-MEcost in the VGC analogue
train ŝMLP 128/32/16, minutessame order — an estimator of 𝑓, e.g. the ridge with pairwise terms
search on ŝ~10⁶ archive iterations, freefree — this is where annealing / any subset search runs
ground200 games per candidate, 10,000 candidates totala batch of simulated battles per team — the budget that rules everything

The three facts to keep

  • Same budget, more quality. At an identical 10,000-evaluation budget: QD-score 338.52 vs 136.89, best win rate 98.4% vs 90.6%, cells filled 31.86% vs 14.36% (DSA-ME vs plain MAP-Elites). QD-score (§4.2.2) = "the sum of the objective values of all solutions in the ground-truth archive" — simulator-evaluated elites only, never the surrogate archive.
  • Train the estimator on search-generated, diverse candidates. The same surrogate trained on random candidates (Offline DSA-ME) drops to 194.9 — the search must feed the estimator the region it exploits.
  • The surrogate predicts a smoothed proxy + the measures, not win rate — average end-of-game health difference carries more signal per game than a win/loss bit.

The unpublished step

DSA-ME's opponents are six decks weighted evenly. Re-aiming this loop at a frequency-weighted meta-team list — 𝑓's opponent structure — appears in no published paper (verified by two sweeps, 2026-08-19).
