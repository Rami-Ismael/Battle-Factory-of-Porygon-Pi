First, smoothness.

Informally, a landscape is locally smoother when small changes to the input tend to produce small changes in the score.

For a Pokémon team, we first define “nearby”: one legal edit under a specified protocol. A move replacement, ability change, and Pokémon replacement can have different consequences, so we inspect them separately.

A precise definition needs a distance and a scale

Classical mathematical smoothness concerns derivatives in a continuous space. A smooth function can still be steep and sensitive. For discrete teams, define a neighborhood and summarize the score changes under its edit protocol.

S(T) = median over sampled neighbors T′ of |f(T′) − f(T)|

Here, f(T) is expected win rate under a fixed evaluation setup. This is a possible summary of local sensitivity, not a derivative or a universal definition of smoothness.

    What would the Pokémon experiment collect?

    Sample neighborhoods around 50 random legal teams and 50 top-placing teams. Evaluate several edits per starting team with the same protocol and report uncertainty. Compare move, ability, and Pokémon edits separately. Neither group is assumed to be more sensitive before measuring.
