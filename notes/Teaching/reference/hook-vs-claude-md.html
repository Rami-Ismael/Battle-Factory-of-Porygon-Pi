Hook vs CLAUDE.md

Who runs the rule decides what the rule can do.

The sorting rule

  1. Needs judgement? CLAUDE.md.
  2. Must hold even when Claude forgets or disagrees? A tool hook gate on the call that would break it.
  3. A reminder beside the newest prompt? A prompt hook note. It still only asks.

Limits

No hook can make Claude start a subagent; a tool hook can only block a different action. A tool hook on Edit and Write never sees an edit made through Bash.
