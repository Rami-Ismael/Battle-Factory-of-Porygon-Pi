Set cover vs maximum coverage

One-page reference. Same ingredients — universe U, family of subsets — different fixed quantity.

Reference sheet · created 2026-08-18 · from Lesson 0001

Set cover — cover all, minimise count/cost

min ∑j cj xj
s.t. ∑j : e ∈ Sj xj ≥ 1  ∀ e ∈ U
xj ∈ {0,1}

Fixed: the target — every element.
Free: how many / how costly the sets.
Weighted = costs on sets.
Greedy: repeatedly add the set with the best (new elements ÷ cost); stop when U is covered.
Guarantee: ≤ Hn · OPT, Hn = 1 + ½ + … + 1/n ≈ ln n. Best possible up to low-order terms (Feige 1998).
Infeasible if some element is in no set.

Maximum coverage — fix k, maximise covered weight

max ∑e we ye
s.t. ∑j xj ≤ k
ye ≤ ∑j : e ∈ Sj xj  ∀ e ∈ U
xj, ye ∈ {0,1}

Fixed: the budget k.
Free: how much weight gets covered.
Weighted = weights on elements.
Greedy: k times, add the set with the most still-uncovered weight.
Guarantee: ≥ (1 − 1/e) · OPT ≈ 0.632 · OPT — of the best coverable weight, not of all of U. Best possible unless P = NP (Feige 1998, Prop. 5.2).
Never infeasible.

The mirror

Set cover’s constraint (“all covered”) is max coverage’s objective (“much covered”); set cover’s objective (“few sets”) is max coverage’s constraint (“≤ k sets”). On unweighted instances the two greedies choose identically and differ only in the stopping rule; with weights the choice rule splits as well (max coverage chases element weight, set cover chases cost-effectiveness).

Neighbours you will meet

Budgeted maximum coverage
Sets have costs, elements have weights, spend ≤ B instead of ≤ k sets. Modified greedy still 1 − 1/e. Khuller, Moss & Naor, IPL 1999 (🔒; abstract 🟢).
Soft coverage / “float” model
Each (set i, element j) has a value vij ∈ [0,1]; score an element by the best chosen value: max ∑j wj · maxi∈S vij, |S| ≤ k. Greedy 1 − 1/e (W&S §2.5, Thm 2.16). This is the shape of “beats with probability p” rather than “beats”.
Partial set cover
Cover at least a fixed fraction of U with the fewest sets — sits between the two problems.
Submodular maximisation with a cardinality constraint
The general family all of the above belong to; the 1 − 1/e greedy bound is Nemhauser–Wolsey–Fisher 1978 (🔒).

Vocabulary collisions

coverage
In VGC slang: the types a moveset hits super-effectively. Here: the weight of meta teams a team beats. Say “type coverage” for the slang sense.
set
Mathematical: a subset Si of the universe. Project (CONTEXT.md): a candidate’s competitive configuration. Say “coverage set” / “competitive set” when a sentence could go either way.
weighted
Set costs (set cover) vs element weights (max coverage). Always say which.
