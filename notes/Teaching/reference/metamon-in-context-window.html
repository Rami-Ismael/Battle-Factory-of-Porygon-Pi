What is in the context window

"In-context RL" in Metamon means: the Transformer reads this battle's turns so far, with frozen weights, and the opponent estimate lives in its hidden state. Nothing from any other battle is in the window.

Reference figure · 2026-08-19 · companion to Lesson 0003 · cheat sheet · sources: Metamon Sec. 4 + fn. 1, Fig. 4–5, Table 3; AMAGO Sec. 2–3

Three things the picture is meant to fix

  • Context ≠ corpus. The 950k-trajectory dataset is in the weights (blue box), not the window. "In-context" adaptation is what the green row does at test time with those weights frozen.
  • Context ≠ other battles. Metamon fn. 1: "A natural extension of the context-based framework here would include previous battles between the same players alongside their current battle. This may allow for adaptation in a tournament best-of-three match format." Grey box, top-left: not built.
  • The opponent's team is never an input. Only the opponent's active Pokémon is in each turn's text (Sec. 4: "we are relying entirely on memory to infer the opponent's team"). Everything you know about the other five is in ht because earlier green boxes showed them.

For the VGC version of this figure the grey box would matter more: best-of-three is the tournament format, and team preview + game-1 reveals make game-2 selection the obvious thing to condition on.
