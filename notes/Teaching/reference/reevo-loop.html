The ReEvo loop — reference card

Compressed from Lesson 0005 · Ye et al., NeurIPS 2024 · 🟢 arXiv 2402.01145 · 🟢 repo

One line

Evolutionary search over heuristic code; a generator LLM writes candidates, a reflector LLM writes text about why one beat another, and the meta-objective F — average performance on a cheap instance dataset — does the selecting.

The loop

  1. Initialize — generator + task specification (problem description, heuristic's job, signature) → population of code.
  2. Select — random parent pairs among crash-free heuristics; never pair equal F values.
  3. Short-term reflection — reflector sees the pair + which won → verbal why (per-pair, local).
  4. Crossover — generator: task spec + parents + relative performance + short-term reflection → offspring code.
  5. Long-term reflection → elitist mutation — reflector accumulates hints across generations; generator mutates the current best under those hints.

Definitions

  • Language Hyper-Heuristic: LLM-generated heuristics, open-ended heuristic space, minimal manual intervention.
  • Meta-objective F: expected performance of heuristic h, estimated as average performance on a dataset of problem instances. Must be cheap — it runs once per candidate.
  • Verbal gradient: the reflector's text explaining a score comparison, used as the improvement direction.
  • White-box / black-box view: with / without a problem description in the prompts; black-box = signature + score feedback only.

Repo mechanics

  • Evolved code lives in ./problems/<problem>/gpt.py; the evaluator prints F as the last stdout line.
  • Adding a problem = a task specification + an evaluator script; the loop is problem-agnostic.

The project mapping (pruning rules)

  • individual = filter/penalty function over one team
  • instance data = ranked top teams (retention) + sampled teams (prune fraction)
  • F(rule) = rank-weighted retention × prune fraction — battle-free
  • view = white-box (the LLM knows Pokémon; give it the Reg M-B description)
  • open decision: hard filter vs soft penalty
