Submodular maximization

Vocabulary and one worked decision

Symbol / termMeaning
V / S / kCandidate pool / selected subset / selection limit
f(S)Value assigned to the selected set
Marginal gainΔ(x | S) = f(S ∪ {x}) − f(S)
SubmodularP ⊆ Q, x ∉ Q ⇒ Δ(x | P) ≥ Δ(x | Q)
MonotoneP ⊆ Q ⇒ f(P) ≤ f(Q)

Example: A covers {1,2,3,4}; B covers {1,2,3}; C covers {4,5,6}. After A, B adds 0 while C adds 2. With two slots, greedy chooses A then C.

🟢 Krause & Golovin, Definitions 1.1–1.3; Theorem 1.5.
