A small addition to your opening prompt can make ownership clear when several agents build, review, and improve the same project.

Example chat: Build and judge novel VGC ideas

Where your prompt benefits

Your opening request already assigns makers their own variant folders. It also asks for independent verifiers, a judge, and one final variants/DECISIONS.md.

The gap is at the point where their work comes together: who updates that shared document, and who edits the winning files when several animation makers or fix agents are working?

This is an ambiguity in the prompt, not evidence that the chat actually lost work.

Give the final merge one owner

MakersOwn variant folders and animation copies
Verifiers and judgeOwn report files
→
One integratorWaits for producers, checks outputs, combines selected changes
→
Final outputWinning files and one decision document

Read-only work can stay parallel. Shared writes need either separation or an enforced coordination mechanism.

What changes in practice

Opening prompt leaves unclearThe addition makes explicit
Several agents may contribute directly to the decision document.Each publishes a separate report; one integrator updates the document.
Four animation makers may edit the same winner.Each explores a separate copy; selected changes are integrated afterward.
One agent per fix may produce overlapping edits.Independent fixes run in parallel. Overlapping fixes are isolated or sequenced.
