Writing skills I've loaded

What a count means. One count is one time a skill was loaded in a Claude Code session, either by me calling it or by you typing its slash command. Repeats of the same call in a resumed session are counted once.

Why unslop and technical-writing look low. Both apply automatically. I load them once per session and then reuse them for every reply, so their count is the number of sessions, not the number of passes.
