Score COMPLETE designs with the GP ^dibo0040

Expected improvement (EI):
predicted upside beyond the best known score.
Branch reward = average EI of its completions. ^dibo0041

4. Send the reward back up the selected path ^dibo0043

Increase ancestor visit counts; update their average values.
These are tree statistics. The diffusion model is not retrained.
On the next iteration, selection uses the updated statistics. ^dibo0044

REPEAT → RETURN THE EXPLORED COMPLETE DESIGNS WITH HIGHEST EI ^dibo0049

Paper settings: depth 4 • 5 children per expansion • 5 completions per child • 16 search iterations ^dibo0050
