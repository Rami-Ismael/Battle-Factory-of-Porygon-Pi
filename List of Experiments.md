- [x] Scale experiment — done 2026-08-27 (`src/scale.py`, `results/scale_results.json`, 200 teams per arm): width 0.6M → 2.1M → 7.9M params gives 0.162 → 0.172 → 0.195 (+3.3 points, 3.0 σ; ~+3 points per 10× parameters) — the pre-registered 'width flat' was wrong. - [x] Sampling experiment — done 2026-08-27 (`src/sampling.py`, `results/sampling_results.json`, d=96, 200 teams per arm). The winning half had the SAME distribution as the full set (χ² p = 0.70), so distribution was not why it won — two uniform halves with identical distributions scored 0.147 and 0.188 (4-point seed gap), and the full set replicated at 0.197. Deliberately changing the distribution at equal size shows the losers are load-bearing: keep only ≥0.2 → 0.122, top half → 0.089, ≥0.4 → 0.075, bottom half → no valid team at all. Classifier-free guidance on win rate needs losing examples for contrast; cutting them costs 5–11 points.
- [x] Close the loop — done 2026-08-27 (`src/loop.py`, `results/loop_results.json`): three rounds, 400 proposed → 200 most PMI-surprising battled → all added, same pool and budget. Diffusion proposer: 0.165 → 0.172 → 0.153 (flat, p90 0.29 — fails the ≥0.458 bar; 1–2% of proposals match a real team). Copy-paste proposer: 0.468 → 0.470 → 0.494 (rising, p90 0.667 — passes; 66% of proposals match a real team; best 0.875). Both at the same novelty (PMI surprise 2.6 vs 1.84 for real teams). The diffusion thread is closed on the objective: a dictionary beats it inside the loop as well as outside.
- [x] Condition on strength with a surrogate, not just a label — done 2026-08-27 (`src/ridgeguide.py`, `results/ridge_eval.json`). An additive+pairwise ridge (held-out R² 0.60, zero battle cost) used as closed-form predictor guidance on the species columns: scale 0/2/6/15 → 0.206/0.199/0.191/0.223; best-of-4 filtered by the same surrogate → 0.225. Validity holds at 83–88%. Best-of-4 beats the unguided control by +1.9 points (1.4 σ) — not resolved, and still far under a real team (0.470) or the copy-paste loop (0.494). The surrogate is worth keeping as a free pre-filter, not as a way to close the gap.
