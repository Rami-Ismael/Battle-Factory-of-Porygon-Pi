Getting a chart out of a Python script

"From Python" means writing the chart in Python. The experiment scripts are Python, so a library with a Python version lets the same script that computes the numbers also describe the chart. Without one, the script saves the numbers as JSON and JavaScript in the page draws them.

vl-convert is a Python package (pip install vl-convert-python) that turns a Vega-Lite chart into an SVG, PNG or PDF file. It carries its own small JavaScript engine, so it needs no browser. That matters for Obsidian notes, which show a picture rather than a live chart.
