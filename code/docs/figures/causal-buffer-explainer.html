Encode the context once, then predict in a buffer

What "Efficient Autoregressive Inference for Transformer Probabilistic Models" changes, and why its positional-embedding result doesn't carry over to the 84-field team model.

Hassan, Loka et al., arXiv 2510.09477v2 (April 2026) · figures drawn from the paper's Sections 3 and 5 and Appendix H

1. The cost: re-reading everything at every step

A model like TabPFN reads a set of known points, the context, and predicts new ones. For a joint prediction, it predicts one target, adds it to the context, and reads the whole set again. The paper reads the context once, caches it, and writes predictions into a small buffer that only looks backwards.

2. The mask: who may read whom

One attention mask enforces four rules, so training covers every target in a single forward pass. Click a row to see what that token reads.

3. The ablation: why it doesn't transfer

The paper removed the buffer's positional embedding and the score didn't move. Its causal mask already tells each buffer token how many tokens came before it. Our 84-field model has no such mask: every field reads every other field, and slots are shuffled, so only a slot vector can tell a field which Pokémon it belongs to.
