# Where the 84-field diffusion code departs from MD4 and LLaDA

This table sorts each part of the 84-field discrete diffusion model (code/src/diffusion84.py and its helpers) into our own choice or a technique from the masked diffusion papers MD4 (Shi et al., 2024, arXiv 2406.04329) and LLaDA (Nie et al., 2025, arXiv 2502.09992), where "not in the two papers" means not found in those two papers as read.

| Topic | Our code (file:function, what it does) | Paper (which paper, section/equation/algorithm, short exact quote) | Ours or published |
|---|---|---|---|
| Per-field masking rate | diffusion84.py:sched84 builds one exponent per column from SCHED "16,4,4,1.5,1" (lossdown.py:sched_tensor maps species, ability, item, move, nature to 16, 4, 4, 1.5, 1); stat columns get STAT_EXPONENT 1.0. batch_loss masks a column when rand < t**sched, so the chance a column stays visible is 1 - t**w. The fifth value, "nature" in lossdown.py, is Stat Alignment (the glossary's current name for the same field). | MD4 Section 6 uses a per-token polynomial schedule, alpha = 1 - t^w_i, where the w_i are learned (App. I.2). Our exponents are hand-set, not learned, so the form matches and the values do not. | Ours |
| Loss weight sched/t, divided by 84 | diffusion84.py:elbo_terms multiplies each column's cross-entropy by sched / t, sums over columns, and divides by COLS = 84. | For this schedule the weight is w/t, which is the same as the weight MD4 Eq. 5 gives for alpha = 1 - t^w (derived, not quoted). The division by 84 is ours. | Ours |
| How t is drawn in training | diffusion84.py:batch_loss draws t = ((rand(1) + arange(B)/B) % 1), then permutes it with randperm(B) and clamps to at least 1e-3. The stratified spacing is the MD4 scheme; the random permutation and the clamp are ours. | MD4 Algorithm 1: t_i = mod(u + i/B, 1), a stratified draw across the batch. | Published |
| Slot shuffling each batch | diffusion84.py:shuffle_slots gives each team a random Pokémon order (argsort of rand), applied to the 48 field columns and to the Stat Points together. | Not in the two papers as read. Both papers treat the sequence as fixed. | Ours |
| Legal filter in training loss | diffusion84.py:elbo_terms and Model84._logprobs set logits that break the rules to -1e4 (masked_fill) before the log-softmax, then take the log of the mixture of networks with logsumexp. Legal means the Pokémon construction rules in lossdown.py:Tables.allowed (clauses, compatibility, move order). | Not in the two papers as read. Both use unconstrained token vocabularies. | Ours |
| Legal filter while sampling | diffusion84.py:Model84._legal returns the allowed values for the column being filled (Stat Points from stat_points.allowed_stat_points; otherwise Tables.allowed, an optional lookahead rule, and a rule that every Pokémon keeps at least one move). It is never empty and never [MASK]. Sample sets disallowed logits to -inf. | Not in the two papers as read. | Ours |
| Ask dropout 0.15 (classifier-free guidance) | diffusion84.py:batch_loss sets ww to NaN for a random 15% of teams (p_uncond = 0.15), so the network sees an empty ask. A matchup row also drops whole rows (0.3) and single columns (0.2). | Classifier-free guidance (Ho and Salimans, arXiv 2207.12598, cited by LLaDA) trains with the condition dropped; the 0.15 value and the matchup drops are ours. | Ours (method published) |
| Time input to the network | diffusion84.py:Net84.forward adds a projection of t (tproj(t)) to every column, next to the position and word embeddings. | MD4 App. I.2: the network "receives as input the full state x_t of all tokens, while additional time features to encode t are also included". LLaDA App. A.1 (Eq. 11): t "need not be provided as input to the parametric model" under its linear masking. | Published (MD4) |
| Sampling order | diffusion84.py:ORDER = D.ORDER (diffusion.py:309) followed by the Stat Point columns. D.ORDER reveals field 0 (species) for every team slot first, then fields 1 and 2 (ability and item), then fields 3 to 6 (moves), then field 7 (nature). Sample fills one column per pass, so species always come first. | MD4 Algorithm 2 and LLaDA Algorithm 5 (low-confidence remasking) choose positions by a rule or confidence and can fill several per step. Neither uses a fixed field order. | Ours |
| Sampling time grid | diffusion84.py:Model84.sample sets t = 1 - step/COLS for each of the 84 passes, so the network is told t falls from 1 toward 1/84. | MD4 Algorithm 2 uses its own grid of time steps; I did not compare the two grids in detail. | Ours |
| Temperature | diffusion84.py:Model84.sample divides the masked logits by temperature before the multinomial draw. | Not in the two papers as read. | Ours |
| Guidance mixing | diffusion84.py:Model84.sample mixes log-probabilities as lc = guidance * lc + (1 - guidance) * uncond, where uncond comes from the same network with the ask set to NaN. | LLaDA App. A.2, Eq. 16 (unsupervised classifier-free guidance, from Nie et al. 2024): p̃ ∝ p(r₀ given p₀, r_t)^(1+w) / p(r₀ given m, r_t)^w, the same mix with guidance = 1 + w; it cites Ho and Salimans, "Classifier-free diffusion guidance" (arXiv 2207.12598). | Published (LLaDA) |
| Validation draws | diffusion84.py:val_loss runs reps = 4 passes with seed 12345 and batch 512. For each team, t is stratified across the four reps as (r + rand)/reps, clamped to at least 1e-3. Slot orders and masks are fixed per seed, so models are scored on the same draws. | The stratified spacing follows MD4 Algorithm 1; the four reps, fixed seed and shared draws across models are ours. | Ours |
| Stat Points tokens | diffusion84.py:Model84.sample stores each Stat Point as value + 1 (values 0 to 32), with STAT_EXPONENT 1.0 in the schedule. | Not in the two papers as read. | Ours |
