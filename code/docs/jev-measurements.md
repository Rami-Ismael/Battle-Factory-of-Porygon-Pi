# Jev and Mercury measurements

Generated by `scripts/jev_numbers.py` from `~/vgc-data/jev/rebattle-heldout.json` and each grid's `panels.json`; rerun it after any battle step. Do not edit by hand.

Intervals are 95%, from resampling the five unmasked teams.

- **Usable win rate:** over all 270 masks; a mask with no legal team scores 0.
- **When legal:** over the masks this model filled legally. Two models' when-legal numbers sit on different masks, so never compare them.
- **Same masks:** over the masks both models filled legally. This is the only fair head-to-head.

A mask is an unmasked team with some fields hidden; each model fills them in. Mercury runs at four reasoning-effort settings: off, low, medium and high. Each model row names the prompt its teams came from:

- **Mask Lab rules prompt:** the Mask Lab pipeline's `regmb` prompt, which names Regulation M-B and states the rules the Showdown team checker enforces.
- **Tuned prompt:** instructions rewritten by GEPA, DSPy's reflective prompt optimizer, with GPT-6 Luna, sent with answer types that allow only legal choices; optimization run `dspy-optimize-luna4-20261016`, program SHA-256 `b16ce050756f`.
- **No prompt:** Jev picks every value from a list of legal options; the random fill draws one at random.
