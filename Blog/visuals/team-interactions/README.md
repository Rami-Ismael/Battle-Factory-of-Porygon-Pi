# Same team. Different interactions.

Blog figure focused on context-dependent contributions. Open `index.html`, change the weather, then select Venusaur, Archaludon, or Basculegion to follow the mechanism. “Watch the change” plays a finite, approximately 13-second sequence; selecting anything interrupts it. The roster stays fixed. This is a mechanism illustration, not a simulation or a measured effect on win rate.

## Embed

Publish `index.html`, `style.css`, `script.js`, and the six PNG sprites together under `/visuals/team-interactions/`. No libraries, external fonts, or network calls are needed. An iframe isolates the styles from the blog:

```html
<iframe src="/visuals/team-interactions/index.html"
  title="How weather changes relationships within a Pokémon team"
  loading="lazy"
  style="display:block;width:100%;height:1600px;border:0;">
</iframe>
```

Adjust the iframe height to your site's column width. Narrow layouts stack the explanation beneath the graph; readers can also open the page directly. `preview.png` and `preview-sun.png` provide static alternatives.

## Interpretation

- Rain boosts Water-type damage by 1.5 and halves Fire-type damage; sun reverses those modifiers.
- Chlorophyll doubles Speed in sun and provides no Speed multiplier in rain.
- Electro Shot attacks without its usual charging turn in rain. This example's Archaludon holds Leftovers rather than Power Herb.
- Weather Ball becomes Water in rain and Fire in sun. The displayed 1.5 modifier is only the weather damage multiplier, not its total power change; weather also changes Weather Ball's base power.
- Reflect and Light Screen illustrate support usable in either weather. Their effectiveness still depends on the battle.
- The graph is a selected set of possible relationships in a six-Pokémon roster. It does not put all six into battle or claim that one mode always wins. Each player brings four; weather is shared with opponents, who can also exploit or replace it.
- “Nonseparability” names the optimization concept motivating the figure. This example alone does not quantify objective interaction order, prove ruggedness, or establish that Pokémon is harder than a benchmark.

## Motion and verification

Occasional explanatory animation: SVG connections stay in place while emphasis changes, preserving each relationship's position. CSS opacity transitions and Web Animations API transform/opacity transitions use the shared `cubic-bezier(.23,1,.32,1)` curve. UI feedback is 140–240 ms; explanatory emphasis is 400–650 ms. Keyboard actions and reduced-motion mode update immediately. Playback stops when the page is hidden.

`check.cjs` uses the local Codex Playwright runtime to check all six interaction states, weather switches, reduced motion, keyboard control, interrupted/full playback, and overflow from 320 to 1240 pixels. Update its absolute dependency path to run elsewhere. Browser screenshots are generated by the same check.
